# Canary

[English version](README.md)

Сканеры пайплайна обновляются автоматически. Дефектное обновление сканера может отключить
обнаружение проблем без ошибки. Тогда проверка проходит, но сканер не находит проблем.

Этот проект содержит известные проблемы. Self-test запускает каждое обновление сканера на этом
проекте. Затем `scripts/check_canary.py` проверяет отчёты. Каждый отчёт должен содержать каждую
находку из [expected.yml](expected.yml). Если находки нет, self-test не проходит. Тогда Renovate
не мёржит обновление.

Проверки «отчёт содержит хоть какие-то проблемы» недостаточно. Обновление сканера может сломать
обнаружение для одного формата файлов и сохранить для другого. Поэтому в canary есть известная
проблема для каждого формата и каждого сканера, и self-test проверяет каждую.

| Файл | Сканер | Известная проблема |
| --- | --- | --- |
| `config.env` | Betterleaks | Поддельный секретный ключ age. |
| `allow-comment.env` | Betterleaks | Тот же ключ с комментарием `gitleaks:allow`. Пайплайн отключает такие комментарии. |
| `app.py` | Semgrep | Инъекция команды и инъекция в eval из запроса. На строке с eval стоит комментарий `nosemgrep`. |
| `requirements.txt` | Grype | PyYAML 5.3 с критическими уязвимостями. |
| `pyproject.toml`, `uv.lock` | Grype | urllib3 1.23 — транзитивная зависимость, которая есть только в `uv.lock`. |
| `Dockerfile` | Grype по собранному образу | Alpine 3.10.0 с исправленными уязвимостями. |
| `bad.Dockerfile` | hadolint | `sudo` в `RUN` и `ADD` под комментарием `hadolint ignore`. |
| `.github/workflows/bad.yml` | zizmor, actionlint | `pull_request_target` и инъекция в `run`. |
| `.gitlab-ci.yml` | poutine | `curl \| sh` и `CI_DEBUG_TRACE`. |

Чтобы добавить проверку или формат файлов:

1. Добавьте в эту папку файл с известной проблемой.
2. Запустите canary и найдите ID находки в отчёте.
3. Добавьте ID в `expected.yml`.

Все секреты в этой папке поддельные. GitHub и GitLab не запускают CI-файлы из этой папки.
